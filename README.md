# MCP Hub

MCP Hub 是為單一使用者規劃的 MCP 管理工具，目標是把分散的服務設定、啟停操作與日誌集中到一個本機介面，並讓使用者在外出時，仍能從 iPhone 的 Open Minis 經單一入口使用不同 MCP 工具。

**目前處於實作階段。** T-001（iPhone 經私人單一入口呼叫兩種 MCP）與 T-002（本機單一入口安全控制 Gateway）已通過驗收與審查；T-003 起尚未實作。完整範圍與驗收條件以 [PLAN.md](PLAN.md) 為準，各工單的實際進度以 `.harness/state.json` 為權威來源（摘要見 [TICKETS.md](TICKETS.md)）。

已交付部分：`app/` 底下的本機管理介面（單一啟動入口 `app/start-hub.cmd`、Gateway 啟停／重啟、狀態顯示）。管理頁僅供本機存取，MCP 設定的CRUD、下游連線檢查與日誌檢視尚未實作。

## 適合誰

供專案擁有者本人使用：在自己的電腦管理 MCP，並希望在 iPhone 上使用這些工具，減少反覆修改不同設定、重啟程序與搜尋日誌的工作。

## V1 預定能力

- **集中管理**：在同一介面新增、編輯、停用與刪除 MCP 設定。
- **日常操作**：提供單一啟動入口，以及 Gateway 的啟動、停止、重啟操作；關閉管理頁不停止服務。
- **狀態與診斷**：分別查看 Gateway 與下游 MCP 的狀態，測試連線並查看日誌。
- **可控的設定套用**：明確確認後才套用並重啟；失敗時提供錯誤資訊並嘗試恢復上一份可用設定。
- **單一工具入口**：讓 Open Minis 透過同一 Gateway 使用不同下游 MCP。
- **個人遠端使用**：透過私人連線，讓 iPhone 在外出時也能呼叫工具；管理頁維持本機限定。使用時電腦須保持運作與連網。
- **明確管理邊界**：只管理工具自己啟動的程序，檔案操作限制在指定資料夾。

V1 將以兩個無需登入憑證的下游服務進行真實工具呼叫驗收。多人使用、下游登入與憑證管理、公開網路入口、遠端管理、開機自啟及全天候服務不在本版範圍。
