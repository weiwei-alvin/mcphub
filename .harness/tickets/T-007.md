## What to build

使用者能看見 Gateway 與各下游的不同狀態，並對某個下游取得有時間的 MCP 連線檢查結果。

不可依賴後續 T-008 才有錯誤資訊；此張應自行呈現必要診斷。

本張包含交付此結果所需的 UI、業務邏輯、介面、資料保存、輸入驗證與測試。不得把必要的驗證或錯誤處理延到後續工單。

## Acceptance criteria

- [ ] 至少呈現未檢查、可連線、連線失敗、已停用及檢查時間。
- [ ] 必須握手與工具清單皆成功才標為可連線；握手失敗、清單失敗及逾時都不可誤標。
- [ ] 停用狀態覆蓋舊成功結果；單一下游失敗不把其他服務誤標失敗。
- [ ] 說明檢查結果不等於所有工具已成功執行。
