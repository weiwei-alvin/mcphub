# T-003：從管理頁新增並安全套用 MCP

**Status:** COMPLETE — runtime state 已有驗收與 review PASS；後續 acceptance 仍依本張條件追蹤。
**Blocked by:** T-002
**Type:** 使用者功能垂直切片

## 需求追溯

- Scope：S-02、S-04。
- User Stories：US-02、US-07、US-08。
- PLAN 驗收：AC-02、AC-05、AC-06。
- 技術查證：D-03 的儲存部分、D-05 的恢復部分。
- 原始行為定義以 SPEC.md 為準，不擴張 PLAN.md 範圍。

## What to build

從介面新增兩種服務，只有明確套用後才保存並生效；套用失敗時可辨識真正狀態並嘗試恢復。

此張的新增／驗證／套用／恢復是同一完整結果，不拆成無法獨立交付的資料層及介面層。

本張包含交付此結果所需的 UI、業務邏輯、介面、資料保存、輸入驗證與測試。不得把必要的驗證或錯誤處理延到後續工單。

## Acceptance criteria

- [ ] 新增 stdio／Streamable HTTP 所需資料；指出欄位錯誤，不提供秘密憑證輸入。
- [ ] 僅編輯不重啟，按儲存並套用前提示可能中斷。
- [ ] 套用後新服務可真實呼叫，重開管理頁仍保有設定。
- [ ] 無效設定不取代有效設定且既有服務保持可用。
- [ ] 受控啟動失敗時保留錯誤並嘗試恢復；分別驗證恢復成功、恢復失敗、首次啟動無可恢復版本，介面不得假報成功。

## 自動驗證

Golden Path step：AT-003。在專案根目錄執行：

```powershell
python -B tests/acceptance/check.py --ticket T-003
```

由介面新增兩個測試服務並套用，重新載入頁面查到設定，經 Gateway 各呼叫其工具核對結果。

實際程式位於 tests/acceptance/check.py；操作契約、fixture 與環境需求見 tests/acceptance/README.md。環境未就緒時回傳非零，不跳過、不輸出假成功。此命令只涵蓋明列的自動檢查，不代表整張工單全部通過。

VT-02、VT-03 全部受控故障與提示流程必須另測；成功新增的自動檢查不代表恢復流程通過。

審查者必須逐項核對未被上述自動命令涵蓋的 Acceptance criteria，提供實際來源與限制。僅有自動 PASS 或證據欄位完整，均不足以完成工單。
