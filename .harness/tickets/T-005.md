## What to build

使用者可停用一個下游，保留其設定，但 Gateway 不再允許呼叫它。

停用不是卸載或刪除。

本張包含交付此結果所需的 UI、業務邏輯、介面、資料保存、輸入驗證與測試。不得把必要的驗證或錯誤處理延到後續工單。

## Acceptance criteria

- [ ] 由介面停用並明確套用。
- [ ] 重新載入後服務設定仍存在且維持停用。
- [ ] 經 Gateway 呼叫該服務收到明確拒絕，不以 Gateway 全面斷線冒充停用成功。
- [ ] 另一服務仍可成功呼叫。

## 自動驗證

Golden Path step：AT-005。在專案根目錄執行：

```powershell
python -B tests/acceptance/check.py --ticket T-005
```

實際程式位於 tests/acceptance/check.py；操作契約、fixture 與環境需求見 tests/acceptance/README.md。環境未就緒時回傳非零，不跳過、不輸出假成功。此命令只涵蓋明列的自動檢查，不代表整張工單全部通過。
